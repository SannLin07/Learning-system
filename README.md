# Learning System

A learning journal and mentoring workspace for the goal of becoming a Senior Mobile Engineer.

## How to use it

1. Add your existing 90-day plan as `ROADMAP.md` when it is ready. Keep the current topic and week clear.
2. For each study session, copy `journal/TEMPLATE.md` to a dated file such as `journal/2026-10-05.md`.
3. Ask Codex to "Start today's learning session" from this repository. It will read the roadmap and recent journal entries before recommending work.
4. Record what you actually learned, built, tested, and still find difficult. Course completion and mastery are tracked separately.

The mentoring rules are in `AGENTS.md`. The weekly review reminder is scheduled in Codex for Sunday at 6:00 PM Myanmar time.
